# Mini Studio 16 website

This repository publishes the static Mini Studio 16 project site.

The firmware, CAD sources, tests, documentation, and development history live in [CanadaOrNaw/Mini-Studio-16](https://github.com/CanadaOrNaw/Mini-Studio-16). The files here are a dependency-free build artifact generated from that repository.

## GitHub Pages setting

In **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
